Политика конфиденциальности finbot

Действует с 1 ноября 2026 года.

finbot — личный бот одного человека (владельца). Других пользователей у него нет: сообщения от всех, кроме владельца, бот игнорирует и никак не обрабатывает.

Какие данные обрабатываются

  • сообщения, фото чеков и PDF-выписки, которые владелец сам отправляет боту в Telegram;
  • одна Google-таблица учёта владельца — бот читает её и дописывает строки;
  • файлы на Google Диске, созданные самим ботом (папки для чеков и выписок). К остальным файлам Диска у бота нет доступа (scope drive.file).

Где хранятся данные

Результаты работы записываются только в Google-таблицу и на Google Диск владельца. Бот работает на сервере владельца; там хранятся только ключи доступа и служебная база, защищающая от повторной обработки сообщений.

Кому передаются данные

Никому. Данные не продаются, не используются для рекламы и не передаются третьим лицам. Данные, полученные через API Google, используются только для перечисленных выше функций и соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Доступ к Google отзывается на странице myaccount.google.com/permissions, доступ к боту — командой /revoke в @BotFather.

Summary in English

finbot is a private bot used by a single person, its owner; it ignores everyone else. It processes only what the owner sends it, reads and appends to the owner's own Google Sheet, and accesses only Drive files it created itself (drive.file). Data is stored only in the owner's Google account and on the owner's server, is never sold or shared with third parties, and its use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
